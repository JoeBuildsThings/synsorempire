# Synsorempire

A fashion store for Synsorempire in Ibadan, Ogunpa. Customers browse corporate wear, formal shoes, sneakers, streetwear, caps, belts, bags and essentials, then order on WhatsApp. The owner adds and manages products from a private admin area.

## Highlights

* **Product codes.** Every item has a unique code such as SYN0007. It shows on the site and is written into each WhatsApp order message, so the owner always knows which item a customer means.
* **One tap ordering.** Tapping Order opens WhatsApp with the message already written.
* **Payment before delivery.** Stated clearly on every page that matters.
* **Admin area.** Add, edit, feature, hide and delete products, with photos compressed before upload.
* **Fast pages.** Cached for speed, refreshed the moment a product changes.
* **Easy to find.** Sitemap, share preview, clean titles and descriptions.

## Tech stack

* Next.js 16 and React 19
* Tailwind CSS 4
* Supabase for the database, admin login and row level security
* Cloudinary for product photos
* Vercel for hosting
* GitHub Actions for checks and keeping the database awake
